# One Leg Up Website

A tropical-themed static website for the One Leg Up adults-only community.

## Includes

- New visitor welcome section
- Detailed "What to expect" party operations and standards
- Expanded member expectations and conduct guidance
- Past party highlights plus a detailed party archive section
- Upcoming party feature with RSVP call-to-action and event schedule
- Quick FAQ for first-time and returning guests

## Files

- `index.html`: complete site markup
- `styles.css`: tropical visual theme and responsive layout
- `images/`: existing image assets from prior version (currently unused)

## Run locally

Open `index.html` directly in a browser, or serve with:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
